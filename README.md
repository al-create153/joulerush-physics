# Joule Rush N3 and N4

An adaptive physics practice app for National 3 and National 4 pupils (Scottish curriculum). It is one self-contained file: `index.html`.

## What it covers

- Dynamics: speed, acceleration, forces and friction, energy
- Properties of matter: particles and gases, heat
- Three levels: Foundations (below N3), N3 and N4

## How it works

- Questions adapt to each pupil and aim for about 85% right.
- Question types: multiple choice, key words, true or false, fill the gaps, put in order, sort, build an answer, spot the mistake and step-by-step calculations (K, F, C).
- A first wrong choice gets a hint and a second try.
- Short key notes with animations and virtual labs come before new ideas.
- Pupils earn joules, badges, levels, daily stars and mystery boxes.
- Reading support: read-aloud button, dyslexia-friendly font, coloured backgrounds and bigger text. Typed answers are off by default.

## Running it

Open `index.html` in a browser, or host it with GitHub Pages.

Progress saves in the browser on that device. Pupils can copy a progress code from Settings to move to another device, and from Tracking to share with a teacher. The live class dashboard and automatic cross-device saving only work when the app runs as a Claude artifact.
